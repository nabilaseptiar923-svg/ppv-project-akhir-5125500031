# Project Akhir — Timer Belajar

Aplikasi Timer Belajar berbasis web untuk membantu mahasiswa mengelola waktu fokus dan istirahat secara terstruktur.

## Fitur Utama
- Pengatur waktu fokus & istirahat.
- Riwayat dan statistik belajar harian.
- Sistem pencapaian badge tingkat fokus.

## Cara Menjalankan
Buka file `index.html` langsung di browser atau gunakan extension Live Server di VS Code.
