# Laporan Dependensi Pustaka UI

## 1. Pustaka UI
- **Nama**: Bootstrap
- **Versi Terkunci**: `5.3.3` (via CDN jsDelivr)

## 2. Komponen yang Digunakan
1. **Progress Bar**: Untuk menunjukkan progres waktu belajar.
2. **Buttons & Badges**: Untuk kontrol utama dan indikator status mode.
3. **Modal**: Untuk notifikasi visual saat sesi belajar usai.

## 3. Gaya Mandiri
Aturan gaya bawaan ditimpa secara harmonis melalui `src/style.css` tanpa merusak utilitas Bootstrap.

## 4. Pembungkus API
Fungsi pustaka diisolasi pada file `src/ui-pustaka.js`.
